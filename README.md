# 🌦️ Dashboard de Estação Meteorológica

## 📌 Sobre o projeto

Este projeto consiste no desenvolvimento de um **Dashboard Meteorológico**, criado para visualizar e analisar dados coletados por uma estação meteorológica física.

A aplicação foi desenvolvida utilizando **HTML, CSS e JavaScript**, com integração a uma **API REST** para consultar as medições armazenadas em um banco de dados.

O dashboard permite acompanhar informações meteorológicas por meio de tabelas, indicadores e gráficos interativos.

O projeto foi desenvolvido em grupo como parte das atividades acadêmicas do curso de **Ciência da Computação**.

## 🌐 Acesse o dashboard

O projeto está disponível online pelo GitHub Pages:

🔗 **[Acessar Dashboard Meteorológico](https://estacao-meteorologica-cc.github.io/estacao-meteorologica-dashboard/)**

## 🚀 Funcionalidades

- 🌡️ Visualização das medições de temperatura, umidade, pressão atmosférica, luminosidade e sensor de chuva.
- 📅 Consulta de medições por dia, semana e mês.
- 📊 Gráficos interativos utilizando Chart.js.
- ⬅️➡️ Carrossel de gráficos com navegação por setas.
- 🌡️ Cálculo da temperatura máxima, mínima e média do dia selecionado.
- ☀️🌧️ Exibição das condições identificadas pelo sensor de chuva.
- 📋 Tabelas de medições com opção de expandir e visualizar todos os registros.
- 🔄 Atualização das informações conforme a data consultada.

### Descrição dos arquivos

- **index.html:** estrutura principal do dashboard.
- **style.css:** estilos, cores e organização visual.
- **script.js:** consultas de medições por período e funcionalidades de navegação.
- **dados.js:** processamento dos dados, cálculos de temperatura e geração dos gráficos.
- **README.md:** documentação do projeto.
- **CSV:** conjunto de dados meteorológicos incluído no repositório.

## ⚙️ Como funciona

1. O usuário acessa o dashboard pelo navegador.
2. A aplicação realiza consultas à API REST.
3. A API retorna as medições meteorológicas disponíveis.
4. O JavaScript processa e organiza os dados recebidos.
5. As informações são exibidas em tabelas, cartões e gráficos.
6. O usuário pode selecionar outras datas para consultar diferentes períodos.
